Upload File(s)

This example makes use of a third party NuGET package called HttpMultipartParser to parse the request body.
Note: The form's enctype must be set to multipart/form-data.
This encoding allows the form to send input data and files in the same request.

The page is initially loaded with with a GET request from the menu as show in the Request Data display below.
Once the form is loaded and its inputs populated, the Upload button POSTs the form's data back to this URL. HttpMultipartParser decodes the requst and lists input data and file names in the Request Data section.
